- **Status:** DONE

- **Category:** Design / Systems
- **Target Branch:** `feature/build-synergies-design`

## Description

Define the core build archetypes and synergy pathways for the first campaign.
This parent design task determines the specific ball mechanics and relic items that players can combine into powerful builds.

## Core Objectives

1. **Identify Desired Build Archetypes:**
   - Define high-level playstyles that players can pursue during a run.
   - Establish mechanical synergies between ball behaviors, pegboard status effects, and weapon energy channels.

2. **Synergy Linkages:**
   - Connect ball types to specific relic multipliers.
   - Ensure distinct scaling avenues so players do not follow a single dominant strategy.
